# Terms

Trader is a private research tool run by one operator for their own use. These terms exist so the page is not empty; they bind no one else.

- Access: the site is read-only and open only to accounts the operator's Forgejo instance admits. Access can be removed at any time.
- No advice: results, rankings and suggestions are paper-trading research and carry no financial advice. Past backtests do not predict returns.
- No real money: every bot is dry run and the live entry point refuses to run (`docs/live.md`). Nothing here is an offer to trade, hold or manage anyone's funds.
- No warranty: the site and data come as is, with no uptime or accuracy promise.
- Third-party data: venue data stays subject to each venue's own terms (`docs/platforms.md`).
