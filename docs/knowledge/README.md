# Trading knowledge

What a person or agent needs to know about markets to work on this lab, kept beside the code it explains. The lab's own decisions live elsewhere: verdicts in [avenues.md](../avenues.md), the research method in [pipeline.md](../pipeline.md), and the lab brief `research.md` (mindset, method, risk, holding, shorting) in the notes lab project `trader/docs/`.

- [glossary.md](glossary.md): trading terms, from lot size to closing line value, each with where the trader uses it.
- [reading.md](reading.md): books ranked for this lab, what is owned, and notes from reading them.
- [resources.md](resources.md): free docs, papers, blogs, code, courses and podcasts.
- [prediction-markets.md](prediction-markets.md): the evidence on edge in event contracts and sportsbooks, and what it means for each family.

## Adding to it

- One subject, one page. A new subject (crypto market structure, execution, tax) gets its own page and a line above.
- Each claim names its source, whether it was read (primary) or seen in a search summary (snippet), and the date.
- Each page says what the knowledge means for the lab, linking the avenue, family or file it touches.
- Link to the lab's docs rather than restating them; a site word belongs in `web/glossary.toml`.
